# Excel Sales Performance Dashboard

An internship project by **Balram Kumar**, completed during the Data Analyst internship at Renu Sharma Healthcare and Educational Foundation (24 August–24 September 2026).

## Business question
How do sales and profit vary across time, cities and product categories, and which areas deserve closer operational review?

## Workbook
Download `Task_1_Submission_File.xlsx` and open it in desktop Excel to explore the original dashboard and filters. GitHub does not run interactive Excel dashboards.

The original workbook is preserved without modification. It contains `Summary`, `Sales_Dashboard`, `Calculations` and `Raw_Data` sheets. The workflow covers data cleaning and standardisation, Pivot Table reporting and dashboard presentation for stakeholders.

## Verified dataset totals
The supplied workbook contains 30,000 records dated 1 January 2025–31 July 2026.

| Measure | Value |
| --- | ---: |
| Sales | ₹473,378,289.12 (₹47.34 crore) |
| Profit before shipping | ₹149,009,545.59 (₹14.90 crore) |
| Profit / sales | 31.48% |

These totals were checked against the underlying `Sales_INR` and `Profit_INR` columns. They describe the project dataset, not an employer's audited business performance. Profit after shipping is a separate field and should not be confused with the headline profit figure.

## Review notes
The executive summary contains recommendations to explore. Those recommendations are hypotheses, not measured business outcomes. Compare category profit margins as well as absolute profit before making allocation decisions. Monetary dashboard cards use crore-scaled values; interpret their units accordingly.

The workbook uses generic customer labels such as `Customer 1000`. The original dataset's source and redistribution licence were not supplied with the submission; no licence or ownership of the underlying data is asserted here.
